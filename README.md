# 🏏 Cricket Card Rush

A cricket card collection and battle game developed using Unity and C#.

## ✨ Features

- Cricket Player Cards
- Card Collection System
- Team Building
- Card Battle Gameplay
- Match Simulation
- Score Tracking
- Mobile Friendly UI
- Smooth User Experience

## 🛠️ Built With

- Unity
- C#
- Visual Studio
